# AmbitionBox Company Data Extraction

## Project Overview
A Python web scraping project to extract company information from AmbitionBox.

## Technologies Used
- Python
- Jupyter Notebook
- Requests
- BeautifulSoup
- Pandas
- NumPy

## Project Workflow
1. Send HTTP requests to the webpage.
2. Parse HTML using BeautifulSoup.
3. Extract company information.
4. Inspect and analyze the extracted data.

## Project File
- `ambitionbox_company_data.ipynb`
